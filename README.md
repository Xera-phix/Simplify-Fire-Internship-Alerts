# 🔥 Simplify FAANG+ Summer 2027 internship email watcher

Uses the **actual `FAANG_PLUS` set from Simplify's source code**, rather than an outdated hand-made company list. Checks Simplify's Summer 2027 JSON listings, filters for SWE / product engineering / applied AI intern roles, and creates GitHub Issues for newly detected roles. GitHub can then **email you** those Issues.

## Setup (roughly 10 minutes)

1. Create an **empty public GitHub repository** (e.g. `fire-intern-alerts`). Public GitHub-hosted Actions is generally free; a private repo consumes your included Actions minutes and can incur charges. Upload *the contents of this folder* to the repository root, retaining `.github/workflows/fire-alerts.yml` exactly. The `.github` folder is hidden on some systems; ensure it's included.
2. In your repo, go to **Settings → Actions → General**, permit Actions and set **Workflow permissions** to **Read and write permissions** if needed. The workflow also explicitly requests `contents: write` and `issues: write`. Make sure **Issues** is enabled in repo settings.
3. On GitHub, open **Settings → Notifications** (`https://github.com/settings/notifications`), enable **Email** under **Watching**, and check your verified email address. On the new repo click **Watch → Custom → Issues** (or All Activity, which is noisier).
4. Go to your repo's **Actions → Fire Internship Alerts → Run workflow**, leave **test_notification** unchecked and run once. It creates `data/seen.json` and *does not alert on jobs that were already listed*. Confirm you see the successful Actions run and the committed state file.
5. Run the workflow again with **test_notification** checked. It will create a `[TEST]` GitHub Issue. **Verify an email arrives**. Check spam and GitHub's notification routing if not. Do not assume alerts are working until you've tested email delivery.
6. You're set. The workflow checks **every ~10 minutes**, subject to GitHub scheduling delays. New matching listings create an Issue and trigger notification email according to your GitHub settings.

### What it watches

- The company must be in Simplify's **official current 🔥 FAANG_PLUS set**.
- A newly visible, active listing must describe a **Summer 2027** SWE / developer / applied AI / FDE or related internship.
- **AMD is excluded by default** because you already have an accepted offer. Delete `amd` from `exclude_companies` to watch it too.
- **US and Canadian opportunities are included** until you decide how to handle work authorization. This does not verify visa eligibility.
- `only_companies: []` means all Simplify 🔥 companies. Set it to e.g. `["stripe", "riot", "roblox", "figma", "google", "meta", "databricks"]` to get only those names; note that **Riot may not be in Simplify's actual 🔥 set**, so it would remain excluded regardless. For non-🔥 dream companies, use a separate direct-careers monitor.
- Adjust `role_keywords`, `exclude_title_keywords`, and `location_keywords` inside `config.json` as desired.

### Practical limitations

- **Not second-by-second**: Simplify's own data feed is updated in batches (their repository documents a daily external sync). An employer could publish a role well before it appears there.
- GitHub scheduled workflows are **not guaranteed to execute exactly on schedule** and can be delayed or occasionally skipped during high load.
- Public GitHub repository schedules can be disabled after **60 days of no repository activity**; check Actions periodically and re-enable if necessary.
- A job may be missing from Simplify or tagged differently from the expected terms/title; you should independently watch the career pages of your top 5–10 companies for faster discovery.
- GitHub emails must be enabled and tested. GitHub Issue alerts aren't a guaranteed email-delivery SLA.
- You can use `python watch.py --dry-run` locally if your computer has internet to print a sample of current matches without opening Issues or modifying state.

### Copying files to GitHub from a terminal

After creating an empty repository (no README/license generated by GitHub), unzip this starter, open that extracted folder in a terminal, then run:

```bash
git init
git add -A
git commit -m "Set up Simplify fire internship alerts"
git branch -M main
git remote add origin https://github.com/YOUR_GITHUB_USERNAME/fire-intern-alerts.git
git push -u origin main
```

Replace `YOUR_GITHUB_USERNAME` with your actual username. Use GitHub's browser upload if you prefer, but make sure to include the hidden `.github/workflows/fire-alerts.yml` path.

### Switching to a future recruiting cycle

This package intentionally monitors **Summer 2027** only. When Simplify publishes a Summer 2028 internship repository, edit the two URLs near the top of `watch.py` to target it, set `year` to 2028 in `config.json`, and delete `data/seen.json` so the first new run bootstraps the 2028 listings without spamming you. Confirm the 2028 repo path actually exists before changing the URLs.
